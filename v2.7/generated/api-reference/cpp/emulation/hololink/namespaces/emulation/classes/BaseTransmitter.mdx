Abstract base class for all transmitters.

Concrete transmitters (COETransmitter, RoCEv2Transmitter, UDPTransmitter) receive a `DataPlaneCtxt*` and downcast to their transport-specific ctxt (COECtxt, RoCEv2Ctxt, UDPCtxt) — those structs embed the platform [DataPlaneCtxt](/holoscan/sensor-bridge/2-7/api-reference/emulation-api/structs/dataplanectxt) extension as their first member, so the pointer cast is sound.

```cpp showLineNumbers={false}
#include <hololink/emulation/base_transmitter.hpp>
```
