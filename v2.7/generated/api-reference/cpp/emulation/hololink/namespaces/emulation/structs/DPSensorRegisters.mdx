Per-sensor register slice. One instance per unique sensor_id, shared by every [DataPlane](/holoscan/sensor-bridge/2-7/api-reference/emulation-api/classes/dataplane) instance that targets that sensor. Holds the vp_data registers (DP_QP, DP_RKEY, DP_PAGE\_\*, DP_BUFFER_LENGTH, DP_HOST_MAC/IP/UDP_PORT, ...) the host writes per stream.
