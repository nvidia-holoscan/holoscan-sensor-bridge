Per-data-plane register slice. One instance per unique data_plane_id, shared by every [DataPlane](/holoscan/sensor-bridge/2-7/api-reference/emulation-api/classes/dataplane) instance with that id. Holds the hif_data registers (DP_PACKET_SIZE, DP_PACKET_UDP_PORT, DP_VP_MASK) the host writes once per physical data plane.
